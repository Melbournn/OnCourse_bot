Source: «Ислам ғылымхалы» (Әбу Ханифа мәзһабы бойынша), Нұрлан Анарбаев, Еркебұлан Қарақұлов, 2015.

PURPOSE
This file is NOT the knowledge source itself.
It is a routing/index file for an LLM agent.

The agent should:
1) Read the user's question.
2) Identify the best matching SECTION and CHUNK below.
3) If possible, identify a SPECIFIC TOPIC inside that chunk.
4) Return only the routing metadata.
5) The retrieval system then parses/searches ONLY the selected page range/chunk from the PDF.
6) If confidence is low, retrieve at most the top 2 candidate chunks instead of the entire PDF.

  "section_id": "NAMAZ",
  "section_name": "Намаз бөлімі",

ROUTING RULES
- Route by MEANING, not only by exact words.
- Prefer the narrowest chunk that fully covers the question.
- If the question exactly matches one of the SPECIFIC TOPICS, use that topic and its page as a strong retrieval hint.
- For exact-topic retrieval, start at the listed page and include a small overlap (recommended: page -1 through page +2), but never leave the parent chunk unless necessary.
- For broad questions, retrieve the full parent chunk range.
- If a question spans two areas, return a primary chunk and one secondary chunk.
- Never route to the whole PDF unless no section/chunk can be identified.
- Page numbers below are the book/PDF page numbers.
